# 자동 동기화가 어떻게 돌아가는가

이 폴더는 **아무것도 안 해도** 변경사항이 GitHub에 올라갑니다.

## 구조

```
윈도우 예약 작업 (10분마다)
        ↓
 .claude/auto-sync.ps1
        ↓
 바뀐 게 있으면 → git add → commit → pull → push
 바뀐 게 없으면 → 아무것도 안 하고 종료
```

- 저장소: https://github.com/tripleseoi3-ai/mmu-ai-literacy-1
- 예약 작업 이름: `Claude-AutoSync-목포해양대-AI리터러시`
- 실행 기록: `.claude/auto-sync.log` (이 파일은 GitHub에 올라가지 않음)

## 자주 하는 일

**지금 당장 올리고 싶을 때** — 10분을 기다리기 싫으면 PowerShell에서:

```powershell
powershell -ExecutionPolicy Bypass -File "C:\Users\user2\Downloads\목포해양대_1차_AI리터러시_자료\.claude\auto-sync.ps1"
```

**잘 올라갔는지 확인** — 로그 마지막 줄을 보면 됩니다:

```powershell
Get-Content "C:\Users\user2\Downloads\목포해양대_1차_AI리터러시_자료\.claude\auto-sync.log" -Tail 5
```

**자동 동기화를 잠시 끄고 싶을 때**

```powershell
Disable-ScheduledTask -TaskName "Claude-AutoSync-목포해양대-AI리터러시"
```

다시 켤 때는 `Enable-ScheduledTask`로 같은 이름을 쓰면 됩니다.

## 주의할 점

- `auto-sync.ps1`은 반드시 **UTF-8 with BOM**으로 저장해야 합니다. 그냥 UTF-8로 저장하면 Windows PowerShell 5.1이 한글을 깨뜨려 스크립트가 실행되지 않습니다.
- 이 저장소는 **공개**입니다. 개인정보나 비밀번호가 든 파일을 이 폴더에 두면 자동으로 인터넷에 올라갑니다.
- 올리고 싶지 않은 파일은 `.gitignore`에 이름을 추가하세요.
