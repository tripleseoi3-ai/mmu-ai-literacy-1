# 기록지 폴더

실습 중 관찰한 내용을 **직접 적는 파일**을 모아 둔 폴더입니다.
슬라이드에는 양식만 띄우고, 실제 기입은 이 폴더의 파일을 열어서 합니다.

## 쓰는 방법

1. 아래 목록에서 해당 실습의 파일을 텍스트 편집기(메모장, VS Code, 워드 등)로 엽니다.
2. 표의 빈칸과 질문 답을 직접 채웁니다. 각 파일 맨 위에 작성 방법이 적혀 있습니다.
3. 채운 파일은 본인 컴퓨터에 저장해 두세요. 뒤 실습과 2차 수업에서 다시 꺼내 씁니다.

## 파일 목록

| 파일 | 해당 실습 | 무엇을 적나 |
|---|---|---|
| `01_네도구_비교기록지.md` | 실습 02 · 네 가지 챗봇 비교 | 네 도구 × 네 축(사실 근거·최신 정보·긴 자료 처리·답변 구조) 관찰 기록과 도구 선택 기준 |

> 실습이 진행되면서 기록지가 추가됩니다. 파일 이름은 `NN_주제.md` 형식으로 붙이고,
> 새 파일이 생기면 위 표에도 한 줄 추가해 둡니다.

## 참고

- 이 폴더의 자료는 **모두 교육 실습용**입니다. 외부 인용이나 실제 업무 판단에 사용하지 마세요.
- 실습용 데이터 파일(CSV)과 그 설명은 상위 폴더의 `README.md`를 참고하세요.
