# 논문 실습 자료 안내

> **여기 있는 논문은 교육 실습용으로 지어낸 가상 논문입니다.**
> 실제 연구 결과가 아니므로 과제·보고서 등 어디에도 인용하지 마세요.
> 저자, 소속 기관, 학술지, 참고문헌, 표의 수치는 모두 창작한 것이고
> 실존하는 논문·연구자·기관과 관련이 없습니다.

---

## 파일

### `coastal-ferry-cancellation-paper.md`

연안 여객선의 결항 요인을 다룬 영문 논문 형식의 자료입니다.
가상의 군도(Hanbyeol Archipelago) 14개 항로에서 6년간 운항한 41,286편의 기록을 분석했다는
설정으로 작성했습니다.

| 항목 | 내용 |
|---|---|
| 언어 | 영어 (번역 실습이 성립하도록 원문을 영문으로 작성) |
| 분량 | 약 1,700 단어 |
| 구성 | Title · Authors · Abstract · Introduction · Data and Method · Results · Discussion · Conclusion · References |
| 표 | 2개 (선박 규모별 결항률, 풍속·선박 규모별 결항 확률) |

요약할 거리가 남도록 수치를 여러 곳에 넣어 두었습니다.
전체 결항률 9.5%, 선박 규모에 따라 3.9%에서 14.8%까지 벌어지는 차이,
풍속 14m/s에서 40.8%p까지 벌어지는 격차, 하루 4왕복 이상 항로에서 나타나는 6.3%p 차이가
요약에 들어가야 할 핵심 수치입니다.

---

## 어느 실습에서 쓰나요

이 파일 하나를 **실습 03과 실습 04에서 연달아** 사용합니다. 같은 논문을 두 번 다루면서
방식의 차이만 바꾸는 것이 이번 실습의 설계입니다.

### 실습 03 — 직접 쓴 프롬프트로

각자 알아서 프롬프트를 짜서 이 논문의 **국문 번역본 1건과 요약 1건**을 만듭니다.
형식은 정해 드리지 않습니다. 어떻게 시킬지는 본인이 정합니다.

### 실습 04 — 인터뷰 기법으로 다시

**새 대화(세션)를 열어** 인터뷰 기법으로 조건을 먼저 끌어낸 다음,
같은 논문으로 번역·요약을 다시 만들고 **브라우저로 열리는 HTML 파일 1개**로 정리합니다.

두 실습이 끝나면 실습 03의 결과와 실습 04의 결과를 나란히 놓고
무엇이 달라졌는지 확인합니다.

## 참고

- 논문 파일은 마크다운(`.md`)입니다. 텍스트 편집기로 열어도 되고, AI 도구에 그대로 업로드해도 됩니다.
- 파일이 길어 한 번에 붙여넣기 어려우면 파일 자체를 업로드하는 편이 안전합니다.
- 번역 결과가 이상하면 원문 문장과 대조해 보세요. 가상 논문이라도 문장 구조는 실제 논문과 같습니다.
