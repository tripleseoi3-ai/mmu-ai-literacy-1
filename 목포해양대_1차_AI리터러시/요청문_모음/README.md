# 슬라이드 PROMPT·코드 박스 추출본

> 자동 추출: `python3 .claude/skills/_shared/extract-slide-prompts.py --slides-dir ../slides --out-dir . --decks-config ../merge-config.json`

## 왜 별도 파일?

PDF는 CSS `user-select`를 무시해서, 슬라이드의 PROMPT 박스만 깔끔하게 드래그하기 어렵습니다.
강의 진행 중 학생·강사가 프롬프트를 복사해 AI에 붙여넣어야 하므로, 박스별로 별도 .md 파일을 두고 그쪽을 직접 여십시오.

**PDF 뷰어 영역 선택 팁** (보조):
- macOS Preview: `option + 드래그` 사각형 선택
- Adobe Acrobat Reader: `alt + 드래그`
