```
지금까지 인터뷰하고 정의한 내용을 스펙 문서로 만들어 주세요.

아래 여섯 개 파일로 나누어, 각각 마크다운으로 작성해 주세요.
- brd/background.md : 왜 이 일을 하는지
- brd/scope.md : 누구를 위해, 어디까지
- prd/requirements.md : 무엇이 나오는지 (번호를 붙여서)
- prd/constraints.md : 지켜야 하는 제약
- prd/done.md : 완료 기준 (체크박스 형식)
- prd/verify.md : 각 기준의 확인 방법

내가 답하지 않아 비어 있는 항목은 지어내지 말고
"확인 필요"라고 표시해 주세요.
```
