# 1일차 · 질문을 고도화하고 스펙으로 굳히기 · 슬라이드 8: 인터뷰 요청문

> 원본: `slides/03_prompt_spec.html` (슬라이드 8)
> 박스 종류: `data-copy` · 강의 진행 중 학생·강사가 복사해 그대로 사용

```
지금부터 나를 인터뷰해 주세요.

주제: [내가 만들고 싶은 것 또는 하고 싶은 일을 한 줄로]

진행 규칙
1. 질문은 한 번에 하나만 해주세요.
2. 내 답을 듣고 다음 질문을 정해 주세요.
3. 내가 "모르겠다"고 하면 선택지를 3개 제시해 주세요.
4. 목적, 사용자, 범위, 제약, 완료 기준을 빠짐없이 확인해 주세요.
5. 더 물을 것이 없으면 인터뷰를 끝내고 알려 주세요.

준비되면 첫 질문부터 시작해 주세요.
```
